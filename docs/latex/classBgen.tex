\doxysubsection{Detailed Description}
Reader and processor for BGEN genotype files (v1.\+1–v1.3). 

This class provides utilities for\+:
\begin{DoxyItemize}
\item Reading the BGEN header block (variant/sample metadata)
\item Loading sample identifiers (from file or embedded block)
\item Matching genotype samples with phenotype/covariate data
\item Locating variant byte positions for multithreaded processing 
\end{DoxyItemize}
