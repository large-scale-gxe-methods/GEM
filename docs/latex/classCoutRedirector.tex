\doxysubsection{Detailed Description}
Redirects standard output (std\+::cout) into the spdlog logging system. 

This class inherits from std\+::streambuf and overrides the virtual functions \doxylink{classCoutRedirector_aefcadde5c5a2053f158adf48abe43204}{overflow()} and \doxylink{classCoutRedirector_ab155b5aef312a0028f8078317f89d4a0}{sync()} in order to intercept characters written to std\+::cout.

Typical use\+:
\begin{DoxyItemize}
\item Installed via std\+::cout.\+rdbuf(\&redirector)
\item Enables capturing of all std\+::cout output into log files and console sinks. 
\end{DoxyItemize}
