Construct the covariance matrix for the random effects. 

This function builds the random-\/effect covariance matrix \hypertarget{classGMMAT_autotoc_md21}{}\doxysubsubsection{\texorpdfstring{used in Woodbury longitudinal generalized linear mixed models (\+GLMMs).}{used in Woodbury longitudinal generalized linear mixed models (GLMMs).}}\label{classGMMAT_autotoc_md21}

where\+:
\begin{DoxyItemize}
\item $\Phi_i$ are sparse kinship matrices
\item $\theta_i$ are variance component parameters stored in {\ttfamily m\+\_\+tau}
\item $I$ is the identity matrix
\end{DoxyItemize}

The resulting matrix has dimension $N \times N\f`.
