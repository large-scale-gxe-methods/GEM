\doxysubsection{Detailed Description}
Structure for storing GEI-\/related data in Eigen matrices. 

This structure holds intermediate matrices and vectors used in the \doxylink{classGMMAT}{GMMAT} + \doxylink{classMAGEE}{MAGEE} workflow, including design matrices, covariance components, residuals, and Woodbury-\/related terms.
